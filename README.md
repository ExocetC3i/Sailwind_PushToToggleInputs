# Sailwind_PushToToggleInputs
Adds customizable hotkeys to toggle forward movement (auto-run) and moving winches in and out in Sailwind.

## Shortcut Keys
Supports push-to-toggle inputs for the following three inputs:
| Shortcut | Default | Behaviour |
| --- | --- | --- |
| Auto-forward toggle | `Z` | Toggles forward movement. Forward or backward keyboard input cancels it. |
| Winch pull in | `Page Up` | While operating a winch, toggles rope pull-in. Press it again to stop. |
| Winch pay out | `Page Down` | While operating a winch, toggles rope payout. Press it again to stop. |

The winch controls will work for any interactable ship control including winches, halyards, and the anchor capstan. May also work with fishing rods, but not recommended as you will likely break your line.
